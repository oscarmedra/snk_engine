# Être, avoir, et la négation

## Être quelque part

```
a yi ka ke              elle est à la maison
ake n'ti ka ke          elle n'est pas à la maison
n waxi-ni ku fayi locolou   mes frères sont à l'école
```

`yi` affirme, `ti` nie. `fayi` s'emploie aussi pour situer — c'est le même mot que
dans le progressif et que le verbe « regarder ».

## Être quelque chose

Avec un adjectif ou un nom, la copule est `ni ya` :

```
towoyinte ni ya         il est malade
xore ni ya              elle est grande
nke faba ka n'ya ni     c'est la maison de mon père
```

L'adjectif peut aussi suivre le nom sans copule : `kille ke gillo` (la route était longue).

## Avoir

Il n'y a pas de verbe « avoir ». On dit que la chose **est chez** quelqu'un, avec `maxa` :

```
waxi-ni filli ya ni maxa     j'ai deux frères
xalisi n'ti maxa             je n'ai pas d'argent
remme ngebe ni a ni maxa     ils ont beaucoup d'enfants
```

## La négation

| Négation | Emploi | Exemple |
|---|---|---|
| `maxa` | passé | `a maxa daga` — il n'est pas parti |
| `mi` | passé, forme courte de `maxa` | `ake mi yige` — il n'a pas mangé |
| `n'ti rini` | futur | `anke n'ti rini daga` — tu ne partiras pas |
| `n'taxa rini` | futur, variante | `anke n'taxa rini daga` |
| `ti` | avec `yi` | `nke ti mula` — je ne veux pas |
| `maxa` | ordre négatif | `maxa daga` — ne pars pas |

`ayi` veut dire non.

## Vouloir, devoir

```
nke yi mula             je le veux
nke ti mula             je ne veux pas
a yi mula i ni kissima wori   il voulait voir mon grand-père
oku na n'xawa …         nous devons …
```

Ces constructions viennent des textes et ne sont pas encore dans le moteur.
