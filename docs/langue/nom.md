# Le nom

## Le déterminant : ke au singulier, ku au pluriel

`ke` et `ku` sont le même mot : c'est **le déterminant**, qui s'accorde en nombre.

| Singulier | Pluriel |
|---|---|
| ka ke (la maison) | kanu ku (les maisons) |
| lemine ke (l'enfant) | leminu ku (les enfants) |
| yite ke (l'arbre) | yitu ku (les arbres) |

Le nom change lui aussi. D'après les exemples recueillis :

| Fin du nom | Pluriel | Exemples |
|---|---|---|
| en `-e` | la finale devient `-u` | lemine → leminu, yite → yitu |
| en `-u`, `-a` | on ajoute `-ni` | mburu → mburuni, banana → bananani |

Le nom `ka` (maison) fait `kanu` : `kanu ku` (les maisons), `kanu tami` (dix maisons).

Après un nombre ou une quantité, le nom prend encore une autre forme, en `-a` :

Au singulier — avec « un » — le nom reste au singulier ; à partir de deux, il passe
au pluriel :

```
lemina m'bane      un enfant
leminu filli       deux enfants
leminu sikki       trois enfants
kanu tami          dix maisons
lemina n'gobo      beaucoup d'enfants   (gobo : des personnes)
yite gebe          beaucoup d'arbres    (gebe : des choses)
lemina lamanu      peu d'enfants
```

## Les possessifs

Le possesseur se place **avant** ce qui est possédé, et c'est le pronom diminutif :

| | |
|---|---|
| `n ka ke` | ma maison |
| `an ka ke` | ta maison |
| `a ka ke` | sa maison |
| `o ka ke` | notre maison |
| `xa ka ke` | votre maison |
| `i ka ke` | leur maison |

Le déterminant `ke` reste donc à sa place, après le nom possédé.

Le même ordre vaut entre deux noms, sans aucun mot de liaison :

```
n'paba ka          la maison de mon père
lemine ke kaye     le cahier de l'enfant
```

`n'paba` montre la particule à l'œuvre : `n` + `faba` (père) donne `n'paba`, où le `f`
devient `p` — voir [La particule](particule.md).

## Il y a

Il n'existe pas de tournure spéciale : on dit que la chose **est** quelque part, avec `yi`.

```
lemine yi ka ke noxo      il y a un enfant dans la maison
leminu yi ka ke noxo      il y a des enfants dans la maison
```

La négation emploie `n'ti` (n'est pas), avec `su` sur le nom :

```
sere su n'ti ka ke noxo   il n'y a personne dans la maison
dji su n'ti yere          il n'y a pas d'eau
```

Littéralement : « aucune personne n'est dans la maison », « aucune eau n'est ici ».

## Les nombres

| Seul | Devant un nom |
|---|---|
| `baane` — un | `lemina m'bane` |
| `fillo` — deux | `leminu filli` |
| `sikko` — trois | `leminu sikki` |
| `naxato` — quatre | |
| `karago` — cinq | |
| `tumu` — six | |
| `nieru` — sept | |
| `seegu` — huit | |
| `koobu` — neuf | |
| `tamu` — dix | `kanu tami` |

Le nombre change de finale quand il compte quelque chose : `baane` devient `bane`,
`fillo` devient `filli`, `tamu` devient `tami`. Le nom qui précède est au pluriel :

```
mburuni filli      deux pains
bananani tami      dix bananes
leminu sikki       trois enfants
```

Les ordinaux se forment sur le même radical :

```
lemina m'pana        le premier enfant   (fana → m'pana)
lemina m'pillandi    le deuxième enfant  (fillandi → m'pillandi)
```

## Ceci et cela

```
ke kundu             ceci
ke doke              cela
ke ka kundu          cette maison-ci
ke ka doke           cette maison-là
```

## Appartenance

`xale` marque l'appartenance :

```
ke kitabe ni nke ni ya xale      ce livre est à moi
ke kitabe ni anke ni ya xale     ce livre est à toi
```
