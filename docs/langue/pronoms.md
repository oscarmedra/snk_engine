# Les pronoms

Le soninké a **deux séries de pronoms** : une série longue et une série diminutive.
La série diminutive est la plus employée dans la conversation courante.

| | je | tu | il / elle | nous | vous | ils / elles |
|---|---|---|---|---|---|---|
| **longue** | nke | anke | ake | oku | xaku | iku |
| **diminutive** | n | an | a | o | xa | i |

## La différence à l'usage

Seuls les pronoms **longs** `anke`, `ake`, `xaku` et `iku` prennent la particule.
Les pronoms `nke` et `oku`, et toute la série diminutive, n'en prennent jamais.

```
ake n'daga      il est parti          a daga      il est parti
anke l'ri       tu es venu            an ri       tu es venu
oku daga        nous sommes partis    o daga      nous sommes partis
```

Voir [La particule](particule.md).

## Les pronoms possessifs

Ce sont les pronoms diminutifs, placés **avant** le nom :

```
n ka        ma maison
a ka        sa maison
o bara      notre cour
i yiramu    leurs vêtements
xa cahiers  vos cahiers
```

La série longue s'emploie aussi : `nke faba` (mon père).

## Le pronom complément

Le pronom placé devant le verbe est le complément. Il s'assimile au verbe comme une
particule :

```
a di nke wori   = a di ŋ'wori      elle m'a vu
```

Les deux écritures se disent.

## Ce qui reste à confirmer

- l'emploi de la série longue en fonction de complément ;
- les formes de politesse, s'il en existe.
