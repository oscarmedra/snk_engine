# La particule

C'est la règle la plus caractéristique de la langue, et celle qui structure tout le
reste. Le locuteur la décrit comme « mettre l'accent » sur le mot qui suit le pronom.

## Les trois règles

**A. Qui la prend.** Seuls `anke`, `ake`, `xaku` et `iku` la prennent.
Jamais `nke`, `oku`, ni les pronoms diminutifs.

**B. Où elle se place.** Elle se colle au **premier mot qui suit le pronom**, quel
qu'il soit : le verbe, le marqueur de temps, ou le marqueur d'objet.

```
ake n'daga              le verbe        il est parti
ake n'yi rini daga     le marqueur     il partira
ake n'di maro n'yiga    l'objet         il a mangé le riz
anke n'yi wurunu       yi              tu courais
```

**C. Sa forme.** Elle dépend de la première lettre de ce mot.

| Initiale | Particule | Exemple |
|---|---|---|
| b, f, m | `m'` | `m'mini` (boire), `m'faye` (regarder) |
| r | `l'` | `l'ri` (venir) |
| w | `ŋ'` | `ŋ'wori` (voir), `ŋ'wuru` (courir) |
| x | `q'` | `q'xobo` (acheter) |
| autres | `n'` | `n'daga`, `n'yige`, `n'sefe` |

Les initiales `n`, `p` et `l` ne sont pas encore confirmées.

## D'où elle vient

C'est un ancien élément nasal qui s'assimile à la consonne suivante. La littérature
décrit exactement le même phénomène : `N + f → mp`, `N + r → ll`, `N + w → ŋw`,
`N + x → ŋq`. Le locuteur le formule autrement — « le `l` sert à mettre l'accent sur
le `r` », « le `q` sur le `x` » — mais il s'agit du même mécanisme.

C'est ce qui explique que le même verbe change d'aspect selon le contexte :
`ri` devient `l'ri`, `rondi` devient `londi`, `fayi` devient `m'payi`.

## Une seule particule, mais deux endroits

Dans une phrase avec objet, la particule apparaît **deux fois** : sur le marqueur `di`
(si le pronom la prend) et sur le verbe qui suit l'objet.

```
ake n'di maro n'yiga      il a mangé le riz
oku di maro n'yiga        nous avons mangé le riz
n di lemine ŋ'wori        j'ai vu l'enfant
```
