# Texte parallèle : au travail (2026-09-20)

Texte français proposé par Claude, traduit par le locuteur. Orthographe d'origine.
Apporte : « il y a », les possessifs, le pluriel, les nombres, l'ordinal,
l'action en cours avec objet, de nouveaux verbes.

La dernière partie du texte français (demain, le soir, le dialogue final) n'a pas
encore été traduite.

| Français | Soninké |
|---|---|
| Ce matin, je me suis réveillé tôt. | Ké suxuba, nké guiri féné. |
| Mon père était déjà parti au champ. | nké faba daga guné. |
| Je travaille tous les jours. | Nké goli ni ya (koota su). |
| En ce moment, j'écris une lettre à mon frère. | Watia kundu, nké fayi létra n'ya safa kati nké waxi. |
| Ma sœur est en train de laver les habits. | Guida niaxaré a do yiramé waqindé niaani mé. |
| Ma mère prépare le repas. | Nké ma fayi yéréxaté n'sorono. |
| Elle est sur le point de partir au marché. | A fayi ké rini daga saxa. |
| Où est ton frère ? | An guida xa ? |
| Il est à l'école. | A fayi locolou. |
| Il étudie tous les jours. | A xarana kotaxu. |
| Qu'est-ce qu'il fait maintenant ? | Aké ni mané débérini watia ? |
| Il écrit dans son cahier. | a fayi safandini i kayé noxo. |
| Notre maison est petite. | O ka a lamané ni ya. |
| Mais il y a beaucoup d'arbres dans la cour. | xa yité gabo niani a noxo. |
| Il y a trois chambres. | kompo siki ya ni a noxo. |
| Mon lit est dans la première chambre. | nké saxura ké fayi kompé fana ké noxo. |
| Hier, je suis allé au marché avec ma mère. | Daru, nké do ma daga saxa. |
| Nous avons acheté du riz, du thé, du lait et de la viande. | O di maro ado téh ado xati ado tié qobo. |
| Le vendeur nous a donné la monnaie. | gagana ké di oku wétiéti kini oku ya (o ya). |
| Nous sommes rentrés avant la nuit. | o yillé kati wuro ké nga roono. |
| Parce que la route est longue. | bawoni, killé ké guillé ni ya. |
