# Texte parallèle : le repas du soir (2026-09-25)

Texte français proposé par Claude, traduit par le locuteur. Orthographe d'origine.
Apporte : le vocabulaire de la cuisine, le marqueur `wa`, les états (chaud, bon,
fatigué, froid), la parole rapportée.

| Français | Soninké |
|---|---|
| Ce soir, ma mère prépare le repas. | Ké lélé, n'ma yi yerexaté ké sorono. |
| Elle est dans la cuisine. | a yi sorékompé noxo. |
| Elle allume le feu. | A di yimbé kumu. |
| Elle met la marmite sur le feu et verse de l'eau dedans. | A di barama taxundi, adi dji l'ro a noxo. |
| Elle lave le riz, puis elle coupe les oignons, les tomates et la viande. | a di maro ké wanqi, kémpalé adi bassalou ku kutu, ado tamau n'do tieh. |
| Ma petite sœur balaie la maison. | xoxoné yaxané ké yi bara ké sellana. |
| Moi, j'apporte l'eau du puits. | nké yi nioŋono gédé. |
| Mon frère cherche du bois. | ngui yi suwaŋana. |
| Où est le sel ? | Sapé ké na mina ? |
| Il est dans la cuisine, à côté de l'huile. | a faye sorékompé noxo, téh ké kara. |
| Donne-moi aussi une cuillère, s'il te plaît. | kudu xa kini ŋa, yampimaxa. |
| La nourriture est prête. | yigandé ké duguta. |
| Ma mère appelle tout le monde. | n'ma di o su xiri. |
| Nous nous lavons les mains, puis nous nous asseyons autour du plat. | o di o kitu wanqi, kempalé o taxu yagandé ké kama. |
| Le riz est chaud. Il est bon. | maro ké tayéni, a liŋéni. |
| Mon petit frère mange beaucoup ; il a très faim. | xoxoné ké wa yigené buru, dullé ni a ka ŋa. |
| Mon père mange peu, parce qu'il est fatigué. | n'paba du fo lémané ya yiga, bawoni a tampinté ni ya. |
| Après le repas, nous buvons du thé. | yerexaté ké fallé, o di hatayé mini. |
| Ma mère lave les assiettes et je l'aide. | n'ma wa xollo ku wanqini, nké wa déma na. |
| Mon frère dit qu'il ira dormir tôt, parce qu'il travaille demain matin. | n'guida ti ké dagana soxu féné, bawoni a goli ni ya xumbéné. |
| La nuit est venue, les enfants dorment déjà. | wuro l'ro, lomunu ku xénxé. |
| Dehors, il fait froid. | sélla ké, mulé ni ya. |
